## 🇧🇩 Bangla AI Stack

Three open projects:

- **BanglaTau** — executable Bangla/Banglish benchmark for policy-bound tool-calling agents: [nurunnobejisan/BanglaTau](https://github.com/nurunnobejisan/BanglaTau)
- **niyom** — serverless Bangla RAG over Bangladesh Bank circulars: [nurunnobejisan/niyom](https://github.com/nurunnobejisan/niyom)
- **lambda-afterwork** — safe post-response work for AWS Lambda: [nurunnobejisan/lambda-afterwork](https://github.com/nurunnobejisan/lambda-afterwork)
